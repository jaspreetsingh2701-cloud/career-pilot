# Mockups

Side-panel UI proposals for the MVP (380px wide, 2x PNG exports). Sample data is made up. These are layout proposals, not final visual design.

| File | Screen |
|---|---|
| 01-mapping-review.png | Autofill review for long forms: progress, filters, grouped compact rows, pre-filled and conflict handling |
| 02-document-library.png | Resume and cover-letter library with defaults and per-file actions |
| 03-autofill-result.png | Per-field outcomes after filling; manual upload fallback; optional history record |
| 04-settings-and-data.png | What is stored, backup export/import, history toggle, clear all data |
| 05-messages-copy.png | Message snippets with placeholders, preview and plain-text copy |

Not yet mocked: Profile, Saved answers, History, first-run onboarding, empty and error states.

Tokens and component rules: [../design-tokens.md](../design-tokens.md). Screen behavior: [../ux-screens.md](../ux-screens.md).
